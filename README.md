# 🎵 리듬 탄막 멀티플레이 게임 (Rhythm Danmaku Co-op)

음악의 비트와 주파수를 실시간/사전 분석하여 **모든 플레이어가 동일한 리듬 탄막 패턴을 회피하고 협동하는 웹 기반 멀티플레이어 탄막 액션 게임**입니다.

서버 1대만 실행하면 브라우저를 통해 친구들과 별도 클라이언트 설치 없이 즉시 접속하여 실시간 협동 플레이를 즐길 수 있습니다.

---

## 🌟 주요 특징

- **실시간/사전 멀티밴드 오디오 분석 (`audioAnalysis.ts`)**:
  - MP3 업로드 및 유튜브 음원을 FFT(고속 푸리에 변환)와 스펙트럼 에너지 분석을 통해 주파수 대역별(Kick, Snare, Melody, Hi-hat)로 분해합니다.
  - 음악 구조에 따라 페이즈(`intro`, `groove`, `build`, `drop`, `break`, `finale`)를 자동 판정하고, 이에 맞춰 탄막 밀도와 공격 패턴을 동적으로 조율합니다.
  - 11개의 음계 레인(`y: 0.02 ~ 0.98`)으로 멜로디 볼트가 사각지대 없이 화면 전체를 타격합니다.

- **모듈형 패턴 제너레이터 & 타임라인 빌더 (`timelineBuilder.ts`, `patterns/`)**:
  - 테마별 독립 패턴 생성기(`IPatternGenerator`) 인터페이스 구조 채택.
  - **`NeonPulsePatternGenerator`**: 시드 기반 결정적 의사난수 생성기(`Mulberry32`)를 활용하여 방 번호/곡 시드에 따라 완벽히 동일하고 균형 잡힌 탄막 시퀀스를 빌드합니다.
  - 원시 온셋(`rawOnsets`)과 악기별 특성에 기반한 지향성 킥 쇼크웨이브, 펄스 슬래시 레이저, 앵글 스위프 레이저, 클라이맥스 존 블래스트를 절차적으로 생성합니다.

- **결정적 타임라인 동기화 (Deterministic Synchronization)**:
  - 서버가 오디오를 분석해 `ObstacleEvent`와 `BeatPulse`가 기록된 JSON 타임라인을 생성하고, 전원에게 동일한 `serverStartTime`을 배포합니다.
  - 클라이언트 간의 네트워크 레이턴시 차이와 무관하게 모든 플레이어가 정확히 같은 타이밍과 위치의 탄막을 마주합니다.

- **오디오 반응형 네온 비주얼 엔진 (`NeonPulseTheme.js`)**:
  - **1:1 오디오-비주얼 매핑**:
    - **멜로디 (Melody)**: 배경 그리드(Grid) 발광 및 드롭 전용 화이트-핫 일렉트릭 코어 플래시.
    - **킥 (Kick)**: 배경 격자의 전진 스크롤 가속 및 카메라 펄스/화면 진동.
    - **스네어 (Snare)**: 대각선 슬래시 라인 발광 및 잔향 감쇄.
    - **하이햇 (Hi-hat)**: 부유 네온 파티클 속도 및 방출 제어.
  - **화이트-핫 일렉트릭 코어 (White-Hot Core Flash)**: 드롭 파트 비트 어택 시 선의 중심이 찰나(0.042초) 동안 순백색(#ffffff) 아크로 번쩍인 후 마젠타/시안 네온으로 전환되어 선명한 타격감을 제공합니다.
  - 1.0px 초정밀 레이저 라인과 최대 56px 반경의 선형 네온 블룸(Bloom) 효과.

- **웹 기반 오디오 분석 & 패턴 시각화 도구 (`client/analyzer.html`)**:
  - 오디오 파일(MP3)을 로컬에서 즉시 분석하여 주파수 파형, 감지된 온셋(Kick, Snare, Melody), 페이즈 변화 및 생성된 타임라인 이벤트를 시각적으로 검증할 수 있는 디버깅/검증 대시보드를 제공합니다.

- **협동 멀티플레이 & 부활 시스템**:
  - 1~4인 동시 플레이 지원 (WASD 8방향 이동, 스페이스바 무적 대시, 쉬프트 고속 이동).
  - 목숨 3개, 피격 시 0.8초 무적.
  - 사망한 팀원에게 4초 내로 다른 플레이어가 접근하면 목숨 1개로 자동 부활.

- **치팅 및 백그라운드 악용 방지 (Anti-Tab-Out Web Worker)**:
  - 창을 최소화하거나 탭을 전환해도 인라인 웹 워커(`_bgWorker`)가 백그라운드에서 물리/충돌 연산을 지속 수행하여 무적 꼼수를 완벽히 방지합니다.

- **스테이지 누적 통계 & 새로고침 복구**:
  - 총 3개의 스테이지로 진행되며, 각 스테이지 클리어/실패 시 피격 횟수, 사망 횟수, 부활 횟수, 생존 여부를 기록합니다.
  - 페이지 새로고침(F5) 시에도 이전 스테이지 결과와 누적 통계가 유실되지 않도록 서버 상태 보존이 적용되어 있습니다.

## 🚀 실행 방법

### 1. 사전 요구 사항
- **Node.js**: v18.0.0 이상 권장
- **FFmpeg**: 유튜브 오디오 추출 및 오디오 분석 디코딩에 필요합니다.
  - Windows: `winget install Gyan.FFmpeg` 또는 PATH 환경변수에 ffmpeg 등록
  - macOS: `brew install ffmpeg`
  - Linux (Ubuntu/Debian): `sudo apt update && sudo apt install ffmpeg`

### 2. 서버 설치 및 실행
```bash
# 1. 서버 디렉터리로 이동
cd server

# 2. 의존성 패키지 설치
npm install

# 3. TypeScript 빌드
npm run build

# 4. 서버 실행
npm start
```
서버가 시작되면 `http://localhost:8080`에서 게임이 실행됩니다.  
Express 서버가 `client/` 디렉터리의 정적 에셋을 자동으로 서빙하므로, 별도의 프론트엔드 빌드 도구 없이 브라우저로 바로 접속할 수 있습니다.

> **개발 모드(핫 리로드)로 실행할 경우:**
> ```bash
> npm run dev
> ```

> **포트 변경:**
> 기본 포트는 `8080`이며, 환경변수로 변경할 수 있습니다.
> ```bash
> PORT=3000 npm start
> ```

### 3. 오디오 분석기 실행 (선택 사항)
서버 실행 후 브라우저에서 `http://localhost:8080/analyzer.html`로 접속하면 로컬 MP3 파일의 온셋 분석 및 생성된 탄막 타임라인을 파형과 함께 그래픽으로 미리 확인할 수 있습니다.

## 🎮 게임 조작법 및 규칙

### 조작 키 (Controls)
| 키 | 기능 | 설명 |
| :--- | :--- | :--- |
| **W, A, S, D** | 방향 이동 | 8방향 자유 이동 (화면 경계 충돌 방지 적용) |
| **SPACE** | 무적 대시 | 누른 시간에 비례해 순간 가속 및 무적 판정 (재사용 대기: 0.7초) |
| **SHIFT** | 고속 이동 | 누르고 있는 동안 이동 속도 대폭 증가 |

### 규칙 및 시스템
1. **생명 (Lives)**: 플레이어당 3개의 목숨으로 시작하며, 피격 시 1개가 차감되고 0.8초간 무적 상태가 됩니다.
2. **협동 부활 (Co-op Revive)**:
   - 생명이 모두 소진되어 쓰러진 팀원에게 4초 이내로 다른 생존 팀원이 접근하면 목숨 1개로 부활합니다.
   - 모든 팀원이 동시에 사망하면 스테이지 실패가 됩니다.
3. **스테이지 구성**:
   - 총 3개의 스테이지로 구성되며, 방장이 3곡(MP3 파일 업로드 또는 유튜브 링크)을 모두 등록/검증해야 게임을 시작할 수 있습니다.
   - 스테이지가 진행될수록 장애물 속도와 패턴 밀도가 점진적으로 상승합니다.
4. **결과 및 통계**:
   - 스테이지 클리어/실패 시 및 전체 3스테이지 완주(Game Clear) 시 플레이어별 피격 횟수, 사망 횟수, 부활 횟수, 생존 여부가 상세히 집계됩니다.
   - 브라우저를 새로고침(F5)해도 이전 스테이지 결과와 누적 통계가 유지됩니다.

## 📡 탄막 및 장애물 시스템

| 장애물 유형 (`ObstacleType`) | 트리거 악기 | 설명 |
| :--- | :--- | :--- |
| **`shockwave`** | Kick (드럼 킥) | 화면 중심 또는 거점에서 외곽으로 느리게 확산되는 도넛형 충격파 (대시 회피 가능) |
| **`sweep_laser` / `laser`** | Snare (스네어) | 경고 선 생성 후 빠르게 회전하거나 가로/세로를 가르는 고위험 레이저 빔 |
| **`melody_bolt`** | Melody (신스/보컬) | 11개 음계 레인(`y: 0.02 ~ 0.98`) 및 플레이어 위치를 겨냥해 화면을 가로지르는 유도/직선 탄환 |
| **`gatling` / `straight`** | Hi-hat (하이햇) | 빠른 비트 속도에 맞춰 연속 발사되는 미세 탄막 궤적 |
| **`wall_crush` / `zone_blast`**| Drop (클라이맥스) | 화면의 절반 이상을 뒤덮으며 압박하는 거대 영역 폭발 및 압축 벽 |

## 🌐 멀티플레이 외부 접속 안내

- **로컬 네트워크 (동일 공유기/와이파이)**:
  - 서버를 구동 중인 PC의 사설 IP 주소(`http://192.168.x.x:8080`)로 접속합니다.
  - Windows 방화벽에서 인바운드 8080 포트가 허용되어 있어야 합니다.
- **외부 인터넷 (공유기 포트포워딩 / 클라우드 VM)**:
  - 클라우드 인스턴스(AWS EC2, Oracle Cloud 등)에 배포 시 인바운드 보안 규칙에서 `8080` 포트를 개방합니다.
  - 도메인 연결 시 Nginx 리버스 프록시와 Let's Encrypt SSL/TLS 인증서를 적용하여 HTTPS/WSS 환경을 구축하는 것을 권장합니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**:
  - HTML5, Vanilla JavaScript (ES Modules)
  - HTML5 Canvas API (하드웨어 가속 2D 렌더링)
  - Pure Vanilla CSS (사이버펑크 네온 디자인 시스템, HSL 팔레트)
  - Web Worker API (백그라운드 물리 루프 및 치팅 방지)
- **Backend**:
  - Node.js, TypeScript
  - Express (정적 서빙 및 오디오 처리 API)
  - `ws` (실시간 저지연 양방향 WebSocket 통신)
  - Multer (오디오 파일 업로드)
  - `youtube-dl-exec` (yt-dlp) + `ffmpeg-static` (유튜브 음원 파싱 및 PCM 변환)
